## Linux storage checks

Both runs used Rust 1.99.0 and Linux kernel 7.0.14-linuxkit in restricted containers on an ARM64 Docker daemon. Each used a fresh ext4 Docker volume (`rw,relatime,discard`), no network or capabilities, a read-only root, non-root execution, and bounded resources.

- [Native ARM64 report](linux-arm64-2026-10-23.json): passed.
- [Emulated x86-64 report](linux-amd64-2026-10-23.json): passed; native x86-64 evidence is still required.

Each run passed **29 core tests**, cross-process ownership locking, **32 seeded process-kill/recovery cases** spanning **1,008 acknowledged operations**, and a second-container verification after volume reattachment. An externally synchronized acknowledgment ledger checks full values, versions and sequence against the acknowledged state or exactly one known pending operation. These are process crashes with the kernel alive.

Each also exhausted a bounded 64 MiB tmpfs, observed a real **131,072-byte partial POSIX write**, then verified database ENOSPC handling, owner poisoning and recovery retaining the acknowledged anchor. No subsequent large put succeeded before ENOSPC in these runs. This error test does not establish ext4 disk-full or device-cache durability.
